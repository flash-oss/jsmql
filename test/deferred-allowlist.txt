# Allowlist for the deferred-coverage drift test.
#
# Format: each non-blank, non-comment line is `<filepath>::<phrase-substring>`.
# The drift test matches a "not yet supported" / "future work" / "deferred"
# phrase in <filepath> against <phrase-substring> (case-sensitive substring).
# If a phrase line matches an allowlist entry AND has no [DEF-NNN] tag within
# ±2 lines, the test skips it (i.e. treats it as known).
#
# Why allowlist at all? Three reasons:
#   (1) A parallel "fork" session is implementing 11 of the original 23-item
#       batch; tagging those rejection sites would conflict with the fork
#       deleting them. Allowlist instead — entries are removed as each fork
#       wave lands.
#   (2) A handful of spec-section headers (`## Out of scope`, `## Future
#       work`) are *categorical* — their children may individually carry
#       [DEF-NNN] tags, but the header itself doesn't need one.
#   (3) The deferred-system meta-documentation itself describes the
#       deferral phrases — those lines mention the words but aren't
#       deferrals. Allowlist.
#
# CRITICAL RULE: the test fails if an allowlist entry no longer matches any
# phrase. So the allowlist can only shrink — it can never accumulate stale
# entries that mask new untagged phrases.
#
# When you remove an entry: you've either (a) tagged the phrase, (b) shipped
# the feature and the phrase is gone, or (c) cleaned up stale doc wording.
