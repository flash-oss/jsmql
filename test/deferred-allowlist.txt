# This is the allowlist for the deferred-coverage drift test.
#
# Format: each non-blank, non-comment line holds `<filepath>::<phrase-substring>`.
# The drift test matches a "not yet supported", "future work" or "deferred"
# phrase in <filepath> against <phrase-substring>, as a case-sensitive substring.
# When a phrase line matches an allowlist entry and has no [DEF-NNN] tag within
# two lines, the test skips it and treats it as known.
#
# The allowlist exists for three reasons:
#   (1) A rejection site is under active removal. A tag here would only need
#       removal again once the work lands. Use the allowlist instead, and
#       drop the entry with the site.
#   (2) A few spec-section headers (`## Out of scope`, `## Future
#       work`) are categorical. Their child bullets may each carry a
#       [DEF-NNN] tag, but the header itself needs none.
#   (3) The deferred-system meta-documentation describes the
#       deferral phrases itself. Those lines mention the words, but they are not
#       deferrals. Add them to the allowlist.
#
# CRITICAL RULE: the test fails when an allowlist entry no longer matches any
# phrase. So the allowlist can only shrink. It can never hold a stale
# entry that masks a new untagged phrase.
#
# When you remove an entry, one of three things happened: you tagged the phrase, you
# shipped the feature and the phrase is gone, or you cleaned up stale doc wording.
